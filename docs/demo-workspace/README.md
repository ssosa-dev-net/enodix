# Demo workspace

A small, made-up network used for the screenshots in the docs. Open this
folder in enodix (the workspace menu at the top of the sidebar, **Open an
existing folder**) to look around.

Every address is in 198.51.100.0/24, a range kept for documentation, so
nothing here reaches a real device.
There are no passwords in it: the hosts use a credential profile named
`northwind-ops`, which you would create yourself in the Credentials view.
